# Edge Investing Website Agent Notes

Before making any UI, layout, article-card, research-page, dashboard, or brand-facing change in this repo, read `DESIGN.md` first.

`DESIGN.md` is the agent-facing design contract for Edge Investing. It defines the Edge paper/ink editorial system, color semantics, typography, component rules, article conventions, responsive behavior, and do/don't guidance.

Canonical brand source lives outside this repo at:

`brand-assets/edge/edge-investing-brand-bible/`

If repo styling and `DESIGN.md` conflict, prefer `DESIGN.md` for new UI work and then reconcile the implementation cleanly.
